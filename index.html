🧪 LabNotes

Connect to the private GitHub repo where your notes live. Everything is stored there — you can open this page from any computer.

How do I get these? (one-time setup)
  1. Create a private repo on GitHub, e.g. labnotes-data (leave it empty).
  2. Go to GitHub → Settings → Developer settings → Fine-grained tokens → Generate.
  3. Under Repository access pick “Only select repositories” → your data repo.
  4. Under Permissions → Repository → Contents choose Read and write.
  5. Generate, copy the github_pat_… token, and paste it above.

The token is stored only in this browser (like a saved password). It’s never sent anywhere except GitHub.
